# University CS Labs: Algorithms & Data Structures

Этот репозиторий содержит коллекцию лабораторных работ, выполненных в рамках университетского курса. Здесь собраны практические реализации классических алгоритмов и структур данных.

**Основной язык реализации:** Python.

## Структура репозитория

### [Aho-Corasick](./Aho-Corasick)
Реализация алгоритма Ахо-Корасик для мультипаттерн-поиска. Строит префиксное дерево (бор) с суффиксными ссылками, превращая его в конечный автомат для одновременного поиска множества подстрок за один проход по тексту.
* **Где используется:** Антивирусные сканеры, системы фильтрации запрещенных слов, сетевые экраны (IDS/IPS).
* **Время:** $O(N + M + Z)$ *(где N — длина текста, M — сумма длин паттернов, Z — количество совпадений)*
* **Память:** $O(M \cdot S)$ *(где S — размер алфавита)*

### [Backtracking](./Backtracking)
Демонстрация парадигмы поиска с возвратом. Алгоритм планомерно перебирает возможные варианты решения задачи, отсекая те ветви вычислений, которые гарантированно не приведут к корректному результату.
* **Где используется:** Решение комбинаторных задач (судоку, ферзи, лабиринты), генерация перестановок, логическое программирование.
* **Время:** Экспоненциальная или факториальная (например, $O(2^N)$ или O(N!)).
* **Память:** $O(N)$ *(для поддержания стека вызовов)*

### [KMP](./KMP)
Алгоритм Кнута-Морриса-Пратта для эффективного поиска одной подстроки в тексте. Использует префикс-функцию, чтобы при несовпадении не проверять текст заново, а сдвигать паттерн на максимально возможное расстояние.
* **Где используется:** Поиск по тексту (Ctrl+F), базовые задачи биоинформатики, парсинг логов.
* **Время:** $O(N + M)$ *(где N — длина текста, M — длина паттерна)*
* **Память:** $O(M)$ *(для массива префикс-функции)*

### [Levenshtein distance](./Levenshtein%20distance)
Вычисление метрики Левенштейна (редакционного расстояния) с помощью динамического программирования. Находит минимальное количество операций (вставка, удаление, замена) для превращения одной строки в другую.
* **Где используется:** Системы проверки орфографии (spell checkers), автодополнение, нечеткий поиск (fuzzy search), сравнение геномов.
* **Время:** $O(N \cdot M)$ *(где N и M — длины строк)*
* **Память:** $O(N \cdot M)$ *(базовая реализация)* или $O(\min(N, M))$ *(оптимизированная)*

### [Traveling Salesman Problem](./Traveling%20Salesman%20Problem)
Решение NP-трудной задачи коммивояжера: поиск кратчайшего маршрута через все заданные города с возвратом в исходную точку (с использованием динамического программирования или метода ветвей и границ).
* **Где используется:** Оптимизация логистических маршрутов, планирование движения ЧПУ-станков, разводка микросхем.
* **Время:** $O(N^2 \cdot 2^N)$ *(при использовании динамического программирования)*
* **Память:** $O(N \cdot 2^N)$ *(для хранения подмножеств посещенных вершин)*
